# Edit-Lock: Defer Export When Editing In Progress

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent mkdocs livereload from closing the status/notes editor by having the monitor defer its export cycle while a user is actively editing.

**Architecture:** A lock file on disk (`wiki/status/edit-lock.json`) written by the API server, read by the monitor. The client (notes-editor.js, status-editor.js) calls POST `/api/edit-lock` on enter/exit edit mode. The monitor checks the file before each export — if locked and not expired, the export cycle is deferred to the next loop iteration.

**Tech Stack:** ASP.NET Minimal API, vanilla JS, PowerShell 5.1

## Global Constraints

- Lock file path: `{outputDir}/status/edit-lock.json`
- Auto-expiry: 5 minutes from `acquiredAt`
- The monitor never writes the lock file, only reads it
- The API never deletes the lock file, only overwrites it
- Stale lock (expired) is treated as unlocked — monitor removes the file and proceeds

```csharp
private static readonly TimeSpan EditLockDuration = TimeSpan.FromMinutes(5);

private static string GetEditLockPath(string outputPath) =>
    Path.Combine(outputPath, "status", "edit-lock.json");

private static IResult HandleEditLock(string outputPath, EditLockRequest req)
{
    var lockPath = GetEditLockPath(outputPath);
    var dir = Path.GetDirectoryName(lockPath);
    if (!Directory.Exists(dir)) Directory.CreateDirectory(dir);

    if (string.Equals(req.Action, "acquire", StringComparison.OrdinalIgnoreCase))
    {
        var now = DateTime.UtcNow;
        var state = new EditLockState(true, req.ElementId, now, now.Add(EditLockDuration));
        File.WriteAllText(lockPath, System.Text.Json.JsonSerializer.Serialize(state));
        return Results.Ok(state);
    }
    else if (string.Equals(req.Action, "release", StringComparison.OrdinalIgnoreCase))
    {
        var state = new EditLockState(false, null, default, default);
        File.WriteAllText(lockPath, System.Text.Json.JsonSerializer.Serialize(state));
        return Results.Ok(state);
    }

    return Results.BadRequest(new { message = "Action must be 'acquire' or 'release'." });
}
```

```powershell
function Test-EditLock {
    param([string]$WikiDir)
    $lockPath = Join-Path $WikiDir "status" "edit-lock.json"
    if (-not (Test-Path $lockPath)) { return $false }

    try {
        $lock = Get-Content $lockPath -Raw | ConvertFrom-Json
        if (-not $lock.Active) { return $false }

        $expires = [DateTime]::Parse($lock.ExpiresAt, [CultureInfo]::InvariantCulture, [System.Globalization.DateTimeStyles]::AssumeUniversal)
        if ([DateTime]::UtcNow -gt $expires) {
            Write-MonitorLog -Phase "export" -Message "Edit-lock expired; clearing stale lock."
            Remove-Item $lockPath -Force -ErrorAction SilentlyContinue
            return $false
        }

        return $true
    } catch {
        Write-MonitorLog -Phase "export" -Message "Failed to read edit-lock: $($_.Exception.Message)"
        return $false
    }
}
```
